# QRly 💜

QRly is a simple QR code generator built with HTML, CSS and JavaScript.

## Features
- Generate QR codes from website links.
- Generate QR codes from ordinary text.
- Download QR codes as PNG images.
- Clear generated QR codes and input.
- Validate empty input.
- Responsive design for mobile and desktop.

## Technologies Used
- HTML
- CSS
- JavaScript
- QRCode.js library

## How to Use
1. Open the application.
2. Enter a website link or text.
3. Click Generate QR Code.
4. Scan or download your QR code.
